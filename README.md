# 🏃‍♀️ FitTrack – Fitness Aktivite Takip Uygulaması

FitTrack, React Native ve Expo kullanılarak geliştirilmiş modern bir fitness ve aktivite takip mobil uygulamasıdır.

Bu proje, 2 saatlik mobil uygulama geliştirme challenge kapsamında hazırlanmıştır.

---

## 🚀 Proje Özeti

FitTrack uygulaması kullanıcıların:

- Günlük aktivitelerini görüntülemesini
- Aktivite detaylarını incelemesini
- Haftalık istatistiklerini takip etmesini
- Meydan okuma (challenge) ekranlarını görüntülemesini

sağlayan sade ve modern bir mobil uygulamadır.

Proje, temiz kod yapısı, component organizasyonu ve kullanıcı deneyimi odaklı tasarlanmıştır.

---

## ✨ Özellikler

- 🏠 Ana Sayfa (Dashboard)
- 📋 Aktivite Listesi (FlatList kullanımı)
- 📄 Aktivite Detay Ekranı
- 📊 Haftalık İstatistik Ekranı
- 🏆 Challenge (Meydan Okuma) Ekranı

- 🎨 Modern UI (rounded cards, soft shadows, temiz tasarım)

## 💻 Kurulum

Projeyi klonlayın:

git clone https://github.com/esmaotur/ittrack-expo-app.git


Proje klasörüne girin:

cd ittrack-expo-app


Bağımlılıkları yükleyin:

npm install


Projeyi başlatın:

npx expo start


---

## 📱 APK Oluşturma

Android APK oluşturmak için:

eas build -p android --profile preview


Build tamamlandıktan sonra Expo tarafından verilen link üzerinden APK indirilebilir.
